# Ali Bhatkar — Creative Developer Portfolio

A modular, fully responsive portfolio website built with clean engineering and considered design.

## 🚀 Features

- **Responsive Design**: 4 breakpoints (480px, 768px, 1024px, 1440px) with a custom mobile hamburger menu.
- **Glassmorphism UI**: Modern aesthetic with backdrop blurs and subtle glow effects.
- **Dynamic Visuals**: Canvas-based hero animations and interactive project visualizations.
- **Accessibility**: Skip-to-content links, ARIA landmarks, focus-visible states, and `prefers-reduced-motion` support.
- **SEO Optimized**: Semantic HTML5, proper meta tags, and OpenGraph support.

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3 (Vanilla), JavaScript (ES6+)
- **Animations**: Canvas API, CSS Keyframes
- **Integrations**: Razorpay, Web3Forms, TidyCal

## 📂 Structure

- `index.html`: Semantic structure and content.
- `styles.css`: Modular styling and responsive logic.
- `script.js`: Interactive elements, animations, and menu logic.
